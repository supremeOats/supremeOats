## Projects
🟥 [Chaos Project](https://github.com/supremeOats/chaos-project) - CPU-based ray-tracing rendering engine written in C/C++. It was develoveped as part of [Chaos Camp 2026](https://www.chaos.com/chaos-camp) at Chaos.

🐇 [Surface Mesh Simplifier](https://github.com/supremeOats/surface-mesh-simplifier) - Application written in Python using NumPy that simplifies triangulated meshes through iterative vertex pair contraction while preserving the shape and geometry as much as possible. The project is an implementation of the algorithm described in the [paper](https://www.cs.cmu.edu/~garland/Papers/quadrics.pdf) by by Michael Garland and Paul Heckbert.
